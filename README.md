# 🔐 SecurePass – Password Strength Checker

SecurePass is a modern and simple web-based Password Strength Checker developed as a Cyber Security Final Project.

It helps users understand how strong their passwords are and provides suggestions to improve password security.

## 🎯 Problem Statement

Many users create weak or predictable passwords, which can increase the risk of unauthorized access. Users may also not know what makes a password strong.

SecurePass provides instant feedback to help users create stronger passwords.

## 💡 Features

- 🔐 Password strength analysis
- 📊 Password score out of 6
- ✅ Six security checks
- 👁️ Show / Hide password
- ⚡ Strong password generator
- 📋 Copy generated password
- 💡 Password security tips
- 📱 Mobile responsive design
- 🔒 Local browser-based analysis

## 🛡️ Security Checks

SecurePass checks:

1. Password length
2. Uppercase letters
3. Lowercase letters
4. Numbers
5. Special characters
6. Simple or predictable patterns

## 🛠️ Technology Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enter a password.
4. Check the strength score and feedback.
5. Use the password generator if required.
